## 🚀 كيفية الاستخدام

### 1. التشغيل الفوري (أونلاين)
افتح الرابط مباشرة في المتصفح:  
👉 **[https://ehabsk.github.io/wc2026/](https://ehabsk.github.io/wc2026/)**

> ✅ يعمل على الهاتف والكمبيوتر  
> ✅ لا يحتاج تثبيت — لكن يُنصح بالتثبيت للاستخدام دون إنترنت

---

### 2. التثبيت كتطبيق (موصى به)

#### على الهاتف (Android/iOS):
1. افتح الرابط في **Chrome** أو **Safari**.  
2. انقر على زر **⋮** (قائمة) → **"تثبيت التطبيق"** أو **"إضافة إلى الشاشة الرئيسية"**.  
3. افتح التطبيق من الأيقونة — يعمل حتى بدون واي فاي! 📲

#### على الكمبيوتر (Windows/macOS):
- في Chrome: **⋮ → More Tools → Create shortcut… → Open as window**  
- أو انتظر ظهور الزر التفاعلي في أسفل الشاشة → **"تثبيت"**
